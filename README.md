# 实时股票行情查询终端

终端中实时查看美股和 A 股行情，自动刷新，支持同时监控多只股票。

## 安装

```bash
pip install -r requirements.txt
```

## 使用

```bash
python main.py
```

启动后输入股票代码即可查询：

| 市场 | 示例输入 | 说明 |
|------|----------|------|
| 美股 | `AAPL` | 苹果 |
| 美股 | `TSLA MSFT GOOG` | 同时查看多只 |
| A 股 | `600519` | 贵州茅台（自动识别交易所） |
| A 股 | `sh600519` | 带交易所前缀 |
| A 股 | `000001` | 平安银行 |

## 功能

- **实时行情** — 当前价、涨跌额、涨跌幅
- **交易数据** — 开盘价、最高价、最低价、成交量
- **基本面** — 总市值、市盈率
- **技术面** — 52 周最高/最低
- **自动刷新** — 每 10 秒自动获取最新数据
- **多股监控** — 空格分隔输入多只股票代码

## 退出

输入 `quit`、`exit` 或 `q`，也可按 `Ctrl+C`。
