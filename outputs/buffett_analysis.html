一、巴菲特选股标准的量化框架

在筛选之前，先明确"巴菲特式好公司"的硬标准。我们将其分为5道门槛：

维度核心标准量化阈值
1. 持续高ROE长期净资产收益率远超行业平均≥ 15%，理想 ≥ 20%，至少5年以上稳定
2. 宽护城河结构性竞争优势，难以被复制品牌/技术/成本/网络/牌照中至少占一项，且有可验证证据
3. 定价权能持续提价而不丢市场份额毛利率 ≥ 40%，多年稳定或提升
4. 现金创造能力利润是真金白银，不是应收账款经营现金流/净利润 ≥ 0.8（长期均值）
5. 财务稳健低杠杆，不依赖外部融资资产负债率 ≤ 50%（金融/公用事业除外）

说明：以上标准全部符合的公司在任何市场都极为稀缺。巴菲特本人也不要求标的在每一条上都完美——他更看重"护城河的深度与持久性"，其次是"合理的价格"。

2.1 巴菲特五项标准逐一验证

  • ✓
    持续高ROE：完全通过。近5年ROE保持在30%-36%区间，2024年35.6%、2025年32.4%。A股4000+公司中，连续5年ROE>30%的企业凤毛麟角。这本身就是一个极强的护城河信号——没有壁垒的行业，高ROE会迅速被竞争侵蚀。
  • ✓
    宽护城河：超强品牌+文化垄断。茅台不仅仅是酒，它是中国社交货币。53度飞天茅台出厂价969元，市场终端价常年2000元以上——这种"出厂价与市场价的巨大价差"是品牌护城河最硬核的证据。可口可乐都不能做到出厂价与零售价差一倍以上。
  • ✓
    定价权：无与伦比。91.3%的毛利率（2025年），意味着100元收入中只有8.7元是直接成本。过去10年茅台多次提价，销量只增不减。这种价格弹性是巴菲特最看重的品质。
  • △
    现金创造能力：需要解释。2025年经营现金流615亿，净利润823亿，比率75%。表面看有差距，但细看资产负债表：合同负债（预收款）从2024年95.9亿大幅下降到2025年80.1亿——这说明茅台在主动释放预收款确认收入，导致一部分"利润"来自之前收到的现金。长期看，茅台的现金质量无可挑剔。
  • ✓
    财务稳健：资产负债率仅17.9%。总资产2789亿，负债仅499亿。账上现金516亿。几乎零有息负债。这是巴菲特最喜欢的资产负债表——"净现金公司"。

2.2 护城河深度拆解

🏷️
品牌护城河
"国酒"地位无可替代。品牌价值不仅来自质量，更来自历史、文化和政治背书。竞争对手无法用广告或价格战复制这种心智定位。
⛰️
资源垄断
茅台镇15.3平方公里的核心产区拥有独特微生物群落，离开此地无法酿造正宗茅台。这不是专利或技术壁垒，是地理禀赋——时间无法复制。
💰
定价权
出厂价与市场价的巨大价差意味着茅台有巨大的提价空间。即使提价30%，消费者依然会买单。这是定价权最极致的体现。
🔄
社交属性（网络效应）
茅台是商务宴请的"硬通货"。用茅台招待客人传递了尊重和诚意信号。越多人认可这个信号，网络效应越强。

2.3 10-20年后的茅台会怎样？

巴菲特最喜欢的投资是那种"你今天买入，十年后根本不需要看股价"的公司。茅台大概率属于这一类：

  • 需求端：中国高净值人群持续增长，茅台作为"社交硬通货"的需求不会消失。即使年轻人饮酒量下降，高端白酒的"社交属性"不是酒精消费，而是信任信号——这个需求是刚性的。
  • 供给端：茅台酒产能受限于地理条件，年产量约5-6万吨，扩产极为缓慢。稀缺性是天然的。"量"的增长有限，但"价"的增长空间巨大。
  • 定价权前景：当前出厂价969元，终端价2000+元。如果未来10年每年提价5-8%（低于GDP名义增速+通胀），10年后出厂价可达1500-2000元。即使销量不变，利润也能翻倍。
  • 风险因素：政策风险（反腐/消费税改革）、人口结构变迁、消费习惯改变。但这些风险已存在多年，茅台市价依然坚挺。

3.1 巴菲特会买科技股吗？—— 会的，因为腾讯不是"科技股"

巴菲特近年重仓苹果（AAPL），证明了当一家科技公司具备消费品的确定性时，他会毫不犹豫地出手。腾讯的逻辑类似：微信不是社交App，它是中国移动互联网的基础设施。13亿月活用户，日均使用时长超过1小时——这跟巴菲特喜欢的"收费桥梁"（toll bridge）异曲同工。

3.2 五项标准验证

  • ✓
    持续高ROE：21.4%（2025），21.6%（2024）。在1.3万亿净资产规模上维持20%+的ROE，意味着护城河在持续转化为股东回报。
  • ✓
    宽护城河：网络效应（微信生态）。13亿用户 → 小程序/支付/朋友圈/视频号 → 更多开发者和商家接入 → 更强粘性。这不是一个可以被钱砸出来的护城河。竞争对手可以复制一个聊天App，但无法复制13亿人的社交关系链。
  • ✓
    定价权/毛利率：56.2%，且正在改善。从2024年的52.9%提升到2025年的56.2%，主要得益于高毛利的视频号广告和微信电商。腾讯通过生态内的流量分发权，实质上掌握了广告和支付的定价权。
  • ✓
    现金创造能力：极强。2025年经营现金流3355亿港元，远超净利润2489亿。每股经营现金流37港元 vs 每股收益27.4港元，比率135%。这是"现金奶牛"最硬核的证据。
  • ✓
    财务稳健：资产负债率39.1%，资本配置优秀。2025年大规模回购+分红合计超千亿港元。管理层展现了巴菲特最看重的品质——在业务不需要大量再投资时，把钱还给股东。

3.3 护城河深度拆解

🌐
网络效应
微信的13亿月活不是数字，是13亿人的社交关系链。离开微信的成本是"失去与亲朋好友的联系"——这对任何个人而言都是不可接受的。
🔒
转换成本
微信支付绑定了银行卡、小程序、社交关系。企业微信绑定了组织架构和客户关系。一旦深度使用，迁移成本极高。
📊
规模经济
微信生态的边际成本趋近于零。每增加一个用户的成本几乎为零，但广告和支付收入持续增长。这是巴菲特最喜欢的"轻资产高回报"模型。
🎮
IP+社交流量池
全球最大游戏公司+中国最大社交平台=无可比拟的分发优势。王者荣耀、和平精英等IP的生命周期远超普通游戏。

3.4 10-20年后的腾讯会怎样？

  • 微信的护城河不会消失：只要中国社会的数字化进程不逆转，微信作为"数字身份证"的地位就不会动摇。10年后，微信可能成为连接AI Agent、IoT设备、数字支付、内容消费的超级入口。
  • AI时代的受益者：腾讯拥有中国最丰富的社交数据和行为数据。随着AI应用落地，这些数据的商业价值将被重新定价。视频号广告、微信电商、AI客服——这些都是已经可见的增长引擎。
  • 资本回报会持续改善：腾讯已从"疯狂投资"模式转向"精耕细作+回报股东"。减持京东、美团，加大回购力度，ROE从投资驱动转向经营驱动——这对长期股东是巨大的利好。
  • 风险因素：监管政策（游戏版号、数据安全、反垄断）、宏观经济下行影响广告收入、中美科技脱钩。但这些风险在PE 15.6x的价位上已被充分定价。

4.1 这不是一家公司，这是一座"自然垄断资产"

巴菲特在2020年买入日本五大商社时说过，他喜欢"不需要太多管理就能赚钱的生意"。长江电力就是这类资产的极致：三峡、葛洲坝、溪洛渡、向家坝、乌东德、白鹤滩——六大水电站沿着长江一字排开，垄断了中国最大河流的水力资源。水从高处流下，不需要采购原材料，不需要研发，不需要营销。唯一的"成本"是折旧和财务费用——而大坝的实际使用寿命远超会计折旧年限。

4.2 五项标准验证

  • △
    ROE：14.8%——刚好踩线。没有茅台那样亮眼，但对于一个2.3万亿净资产的公用事业公司来说，15%左右的ROE已经证明它是"有护城河的公用事业"（普通电力公司ROE仅6-8%）。ROE偏低的主要原因是高负债率（资产收购带来的财务杠杆），随着债务逐步偿还，ROE有改善空间。
  • ✓
    宽护城河：地理垄断+牌照壁垒。长江干流的水电资源已被六大水电站全部覆盖。中国不会再建第二个三峡。这种护城河不是"难以复制"——是"绝对无法复制"。
  • ✓
    定价权：电力是管制的，但水电成本优势本身就是定价权。水电发电成本约0.05元/度，火电约0.3-0.4元/度。在任何电价水平下，长江电力都是最后一个亏损的发电企业。这不是"涨价权"，是"永不被淘汰权"。
  • ✓
    现金创造能力：经营现金流/净利润 = 175%（2025）。605亿经营现金流 vs 345亿净利润——差额来自巨额折旧（大坝折旧是非现金支出）。实际自由现金流远超账面利润。这是典型的巴菲特式"隐藏价值"。
  • △
    财务稳健：负债率62.9%（2025），在公用事业中属正常。高负债来自收购乌东德/白鹤滩的融资。但这些债务对应的是能产生稳定现金流的优质资产，且偿债计划清晰。与普通企业的高负债有本质区别。

4.3 10-20年后的长江电力会怎样？

  • 确定性极高：水会继续流，大坝会继续发电。不会出现"产品过时"或"被颠覆"的风险。这是几乎零不确定性的生意。
  • 债务消退=利润释放：目前每年约93.7亿的财务费用（2025年报）是沉重的利息负担。随着债务逐步偿还，这部分费用将持续下降，直接转化为利润增长。即使收入不增，利润也会因为财务费用减少而自然增长。
  • 碳中和大背景：水电是最大的清洁能源来源。在碳中和趋势下，水电的价值将被重估。电价市场化改革也可能带来超预期收益。
  • 风险因素：极端气候（连续枯水年）、重大地质灾害、电力体制改革。但这些是概率极低的事件。

六、巴菲特会怎么看待A股/港股的"暴涨暴跌"问题？

这是你提问中最核心的关切——A股和港股经常暴涨暴跌，价值投资似乎水土不服。但如果我们从巴菲特的视角来看，暴涨暴跌恰恰是价值投资者的朋友。

巴菲特原话："股票市场是一个重新分配财富的机制，把钱从没有耐心的人手里转移到有耐心的人手里。"

A股的波动恰恰创造了巴菲特最爱的场景——用5毛钱买1块钱的东西：

  • 茅台在2024年9月跌到过1151元（52周低点），PE仅约17x。一个ROE 32%、毛利率91%的公司以17倍PE交易——如果巴菲特在中国，这会被他视为"用合理价格买入伟大公司"的窗口。
  • 腾讯在2025年高点677.7港元后跌至目前457.6港元，跌幅32%。PE从23x降至15.6x。净利润增长21%，股价却跌了32%——这是市场送给长期投资者的礼物。
  • 关键在于：你是否真的相信这些公司在10年后会比今天更值钱？如果你相信茅台的品牌价值不会消失、腾讯的微信生态不会被颠覆、长江电力的大坝会继续发电——那么短期暴跌只是提供了更好的买入价格。

在中国做价值投资，与在美国最大的不同是：

  1. 波动更大 → 需要更强的心理素质。茅台两年内可以从1539跌到1151再回到1210。没有"市场先生是疯子"的心态，你拿不住。
  2. 政策风险更高 → 需要更关注"买什么"而不是"什么时候买"。教育双减、医疗集采、互联网反垄断——在中国，选错赛道比选错时间致命得多。
  3. 信息披露质量参差不齐 → 只买最简单的生意。茅台的商业模式一张纸就能说清楚，长江电力的资产肉眼可见，腾讯的微信你用每天用——这些公司的"可理解性"远高于大多数A股公司。

最终结论：如果你是巴菲特，你会买什么？

如果巴菲特今天坐在中国，手持现金寻找标的，按他的选股标准，贵州茅台是最接近"完美"的选择——它具备了巴菲特所追求的一切：简单的生意、无敌的品牌、惊人的利润率、不需再投资就能增长的商业模式，以及持续将利润返还股东的能力。PE 18.3x的价格对于一个ROE 32%的企业来说，完全在"合理"范围内。

腾讯控股则是"巴菲特晚年会买的科技股"——就像他买入苹果的逻辑一样：一旦确认微信的用户粘性等同于消费品品牌的忠诚度，15.6倍PE买一个ROE 21%且还在改善的"数字基础设施"，这笔账怎么算都不贵。当前YTD -23%的跌幅，反而让它成了三只标的中估值最有吸引力的那个。

长江电力是给"最厌恶风险的价值投资者"准备的——如果你追求的不是高回报，而是"绝对不会睡不着觉"的持有体验，长江电力是最终答案。它可能不会让你暴富，但它几乎不会让你亏钱（在合理价格买入的前提下）。

关于"10年20年后能看到这个公司会怎样"：如果过去20年（2006-2026）茅台营收从49亿增长到1720亿（35倍），利润从15亿增长到823亿（55倍），那未来20年即使增速放缓到5-8%，利润也会超过3000-4000亿。届时市值3-5万亿是大概率事件。腾讯和长江电力的逻辑同样成立——拥有不可替代资产的公司，时间永远是它们的朋友。
